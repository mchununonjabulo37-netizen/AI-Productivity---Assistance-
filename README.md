# AI-Powered Workplace Productivity Assistant
CAPACITI ASA 17 | Johannesburg Week 17 | mchununonjabulo37-netizen

## Problem
Professionals waste 60% of time on repetitive tasks like emails, meeting notes, task planning.

## Solution
All-in-one AI Assistant built with Python + Streamlit using ChatGPT-4o and Gemini 1.5 prompts.

## Features (All 5)
1. Smart Email Generator - Role-based (Client/Manager/Team) + Tone (Formal/Informal/Persuasive)
2. Meeting Notes Summarizer - Summary + Key Points + Action Items + Deadlines
3. AI Task Planner - Eisenhower Matrix + Time Blocking
4. AI Research Assistant - Simplify complex topics
5. Chatbot Interface - Workplace Q&A

## Tools Used
Python, Streamlit, ChatGPT-4o, Gemini, Notion AI
Prompting: Role, Few-shot, Chain-of-Thought, Structured Output

## Sample Prompts
Email: Act as professional [Audience] expert. Write [Tone] email for [Purpose].
Meeting: Summarize notes, extract Key Points, Decisions, Action Items with owners.
Planner: You are productivity coach, prioritize by Urgency/Importance.

## Run
pip install streamlit
streamlit run app.py

## Responsible AI
Includes validation, no data stored, bias check, disclaimer.
